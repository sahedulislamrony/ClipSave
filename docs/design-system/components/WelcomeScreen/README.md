# WelcomeScreen

First launch: art, one line, one button.

- Glass card floats over two blurred iris orbs so the material reads immediately.
- Copy is capped at a 2-line headline and a 4-word subline. Under the button, a caption states that continuing means agreeing to save only what you have the right to and to the Terms; "Terms" is tappable and opens a dialog with the short terms.
