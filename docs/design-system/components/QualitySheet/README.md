# QualitySheet

Liquid-glass sheet after a link resolves (opened by the share sheet and by Home's Download button).

- Detached sheet (8dp inset, 34dp radius).
- Header: thumbnail, "Choose quality", platform · duration, close button.
- Editable file name (starts as the title, 100 characters max), Video / Audio switch, up to four options best first; the selected row is iris-tinted with a tick. HD / 4K tags on 1080p+ rows.
- One button: **Download**. Size is already on the row.
- If Settings › Quality is not "Ask", this sheet is skipped and the download starts straight away.
- **Playlist variant** (YouTube links with `list=`): folder name, numbering (1 → N · N → 1 · None) with a first-file preview, Video/Audio, fixed quality caps (Best, 1080p, 720p, 480p, MP3, M4A), **Download N videos**, and "Only this video" when the link was a video inside a playlist.
- Errors replace the body with the message, a **Sign in** button when the post needs an account, and Close.
